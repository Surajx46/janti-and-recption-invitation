## 💎 Features & Custom Design

1. **3D Royal Envelope Unveiling**:
   - Guests are greeted with an opulent silk-and-gold gift box sealed with an authentic 3D red-and-gold **"S & M" Monogram Wax Seal**.
   - Tapping the seal triggers realistic seal-breaking animations, a joyful chime, and celebratory confetti.

2. **Authentic Panche Baja Background Music**:
   - Integrated with YouTube Panchebaja track: [Nepali Panchebaja Wedding Ceremony Instrumental](https://youtu.be/Vj4O_4yGU2g) (`Vj4O_4yGU2g`).
   - Starts automatically as soon as the guest taps the royal wax seal to open the card.
   - Floating interactive player with animated equalizer waves and mute/play toggle.

3. **Bilingual Support (English & नेपाली)**:
   - Instant toggle between English and Nepali Devanagari script.

4. **Dual Countdown Tickers**:
   - Live Days, Hours, Minutes, Seconds countdown to both Janti Day (Mangshir 17 / Dec 3) and Reception Day (Mangshir 19 / Dec 5).

5. **Direct Calendar Integration**:
   - 1-click `.ics` download for Apple Calendar, Google Calendar, Outlook, and Android calendar.

6. **Natural Falling Petals Engine**:
   - Canvas-rendered Sayapatri (marigold) and Gulab (red rose) petals gently fluttering across the screen.

7. **One-Click Native Social Sharing**:
   - Mobile native sharing drawer and desktop 1-click clipboard copy in the top navigation bar.

## 🚀 How to Run or Deploy

### Option 1: Direct Browser
Simply double-click `index.html` to open it in any web browser (Chrome, Safari, Edge, Firefox).

### Option 2: Local HTTP Server (e.g. Python / Node)
```bash
# Python
python -m http.server 8000

# Node.js
npx serve
```
Open [http://localhost:8000](http://localhost:8000).

### Option 3: Free Hosting on GitHub Pages / Vercel / Netlify
- Push the repository to GitHub.
- Go to **Settings** > **Pages** > Set branch to `main` and folder to `/root`.
- Your live wedding invitation URL will be instantly active!
